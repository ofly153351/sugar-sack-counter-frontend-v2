# Resume Project Description

##  Sack Counter Frontend v2
**Role:** Frontend Developer  
**Project Type:** Internal web application for  sack/box counting and operational management  
**Tech Stack:** Next.js (App Router), React, TypeScript, Tailwind CSS, React Query, Axios, Zustand, next-intl/i18next

### Project Summary
Developed a multilingual (Thai/English) frontend application for  warehouse operations, covering user authentication, counting workflows, and admin management modules (users, products, vehicles, dashboard).

### Key Responsibilities & Contributions
- Built and maintained a modular frontend architecture using Next.js App Router with clear separation of route groups for `auth`, `user`, and `admin` experiences.
- Implemented core business flows for sack/box counting, including interactive form/table components and upload-driven workflows.
- Developed admin management interfaces for users, products, and vehicles with reusable modal/form/table component patterns.
- Integrated frontend with backend services through a centralized Axios client and domain-based API helper layers.
- Improved data-fetching reliability and UI responsiveness using React Query (query state, refetch strategy, and cache-aware updates).
- Implemented multilingual support (Thai/English) using dictionary-based localization and locale-aware routing.
- Added global state handling for user/session-related UI behavior with Zustand.
- Contributed to AI-assisted image upload flow integration and operational diagnostics utilities (including MinIO troubleshooting support).

### Technical Highlights
- Scalable folder structure organized by domain (`components`, `hooks`, `utils`, `i18n`, `providers`, `store`) for maintainability.
- Reusable UI patterns that reduced duplication across admin CRUD screens.
- Environment-driven configuration and feature flags to support different deployment contexts.
- Strong typing with TypeScript across forms, API contracts, and shared utility modules.

### Resume-Ready Short Version
Built a production-oriented Next.js + TypeScript frontend for a warehouse counting system, delivering multilingual user/admin workflows, reusable CRUD interfaces, API integration architecture, and AI image-upload support with maintainable domain-based code organization.
